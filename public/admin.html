📸 Schritt 1: Avatar-Basisbilder generieren

Generiert fotorealistische Ganzkörper-Model-Fotos mit KI (Flux 1.1 Pro).
Die Avatare werden in neutraler Kleidung erstellt, damit der Try-On die Mode auftragen kann.
Kosten: ~$0.03–0.05 pro Bild

👗 Schritt 2: Outfit via Try-On anziehen

Zieht die zugewiesenen Kleidungsstücke auf den Avatar via IDM-VTON.
Voraussetzung: Avatar-Basisbild + Artikel-Bilder als URL
Kosten: ~$0.01–0.03 pro Artikel

🎬 Schritt 3: Walking-Video generieren

Erzeugt ein Lauf-Video aus dem Outfit-Bild (Minimax Video-01).
Der Avatar läuft wie auf einem echten Catwalk!
Kosten: ~$0.10–0.20 pro Video (5-6 Sekunden)

🚀 Komplett-Pipeline (alle 3 Schritte)

Führt alle Schritte automatisch hintereinander aus: Basisbild → Try-On → Video.
Gesamtkosten: ~$0.15–0.30 pro Avatar
