📱 So postest du auf Social Media

📸 Instagram Reels

  1. Video-Datei auf dein Handy übertragen (USB, Cloud, AirDrop)
  2. Instagram → + → Reel → Video auswählen
  3. Trending Musik/Sound hinzufügen
  4. Caption kopieren und einfügen (Button unten)
  5. Link in Bio auf deine Catwalk-Seite setzen
  6. Veröffentlichen! 🚀

🎵 TikTok

  1. Video-Datei auf dein Handy übertragen
  2. TikTok → + → Hochladen → Video wählen
  3. Trending Sound hinzufügen
  4. Caption kopieren und einfügen
  5. Link in Bio auf deine Catwalk-Seite setzen
  6. Veröffentlichen! 🚀
